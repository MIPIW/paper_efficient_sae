# paper_efficient_sae

KronSAE (Kronecker-factored sparse autoencoder) as a steering control interface — "addressable, not separable." See `PAPER_PLAN.md` for the current framing and `REPORT_FULL.md` for the full experimental record.

## Setup

```
pip install -r requirements.txt
```

This repo depends on [`saprmarks/dictionary_learning`](https://github.com/saprmarks/dictionary_learning), cloned separately (not vendored here — see `.gitignore`).

Raw datasets (Amazon Reviews 2023, ~1.5GB) are not included — see `PAPER_PLAN.md` / `PAPER_SCALE_EXPERIMENT_DESIGN.md` for data sourcing.

Private research repo — work in progress, no manuscript yet.
